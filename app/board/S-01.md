## Decision (user)
Use Better Auth's own built-in plugins and options. No paid Better Auth Infrastructure (sentinel/dash), no custom auth code.

## Goal
- Confirm admin(), organization() (with access control), sso(), passkey(), emailOTP(), openAPI() are the only auth extensions, configured as in M-01.
- Replace the hand-written per-email OTP limit hook with Better Auth's built-in rateLimit (database storage, customRules for the email-otp send and sign-in paths) if it can key per email; if it truly cannot, keep the hook and say why in the code comment.
- Bot protection: Better Auth's built-in captcha plugin on the email-OTP send and sign-in endpoints, provider AWS WAF is not supported by it, so choose the plugin's most privacy-friendly supported provider (Cloudflare Turnstile) behind a config switch, off in dev and tests; and add AWS WAF (managed bot control and rate rules) in front of the API in sst.config.ts as the AWS-native layer.
- Session security from Better Auth options: secure cookies, session expiry and freshAge, revoke other sessions on sign-out-everywhere via the built-in API.
- Docs: list the plugins and protections in docs/tenancy.md; add the captcha provider as a sub-processor in docs/gdpr-audit.md.

status: done

## Goal
Booking an adviser saves a booking (adviser id from the seeded list, slot, mode, what is shared) for the user within their organization; share consent recorded as a consent event with exactly what is shared; the user can see and cancel bookings. Advisers as real users come later: no adviser login now.

## Done when
API tests: create/list/cancel booking, share consent recorded, cross-user/tenant denial; app booking flow persists across reload.

## Backend (review)
`booking` table + `consent_event.detail` (migration 0006). `POST /api/bookings` (gated by `adviserBooking`) records an `adviser_share` consent event with exactly what is shared; `GET /api/bookings`; `POST /api/bookings/:id/cancel` records the withdrawal. In export and erasure. Adviser ids are free text from the app's seeded list (no adviser accounts yet).

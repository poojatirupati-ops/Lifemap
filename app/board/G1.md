## Goal
Audit app/ and api/ against GDPR and Irish DPC expectations: lawful basis per data category, consent records, minimisation, access/portability, erasure (check the reported gap: Delete my data keeps the account row and session), retention, OTP/verification row cleanup, security (encryption, secrets, OTP rate limits, cookie flags, CSRF), PII in logs, data residency and processors (AWS, email provider, Google Fonts and CDN scripts leaking IPs), cookies/ePrivacy, age gate, adviser sharing, DPIA, Art. 22 profiling (money personality, risk profile), Art. 30 records, breach process, offline caching of personal data. No code changes.

## Done when
docs/gdpr-audit.md has a verdict, a findings table (severity, evidence file:line, fix, owner code/legal/ops), a must-fix-before-customers list and a needs-a-lawyer list. Code fixes become follow-up cards.

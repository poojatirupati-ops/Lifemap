# Tenancy in the app: branding, flags, SSO sign-in
status: todo
deps: M-01,F1
files: app/src/auth/*, app/src/shell/*, theme loading, account screens

## Goal
On load the app fetches GET /api/tenant for the current host and applies branding by overriding the CSS colour tokens and logo/name (no layout change), hides features whose flags are off, and shows 'Sign in with <provider>' on the account screen when the tenant has SSO. Sign-in, active organization and sign-out use the Better Auth client (organization and SSO client plugins). LifeMap Direct looks exactly like today.

## Done when
Pixel check unchanged for LifeMap Direct; a test tenant with other colours renders with them; a flag off hides its entry point; SSO button appears only for SSO tenants.

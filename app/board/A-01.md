# Product analytics and session recording with PostHog, behind consent
status: done (real PostHog key not yet tested)
deps: O-01 (account consents), A1 state cleanup
files: app/src/analytics/* (provider only), account consent step, Me > Privacy, api consents kinds, api DELETE /api/me, docs/gdpr-audit.md, docs/tenancy.md

## Goal
- Library: posthog-js with posthog-js/react (PostHogProvider, usePostHog). PostHog Cloud EU (https://eu.i.posthog.com) unless the team self-hosts; key and host from Vite env, never hard-coded.
- Consent first (GDPR + ePrivacy): PostHog is not loaded and sets no cookie or storage until the user opts in. Init with opt_out_capturing_by_default: true and persistence 'memory' until consent; after consent persistence 'localStorage+cookie'. No banner is needed before sign-in because nothing non-essential runs.
- Ask once at account creation: an optional, unticked "Help improve LifeMap: anonymous usage analytics and session recordings" box next to marketing; changeable any time in Me > Privacy. Stored through the existing consent events API as kind "analytics" with wording version (grant and withdrawal); withdrawal calls posthog.opt_out_capturing() and clears its storage.
- Privacy in recordings: maskAllInputs and mask all text by default (session_recording maskTextSelector '*'), unmask only static UI copy marked with a ph-no-mask-safe class if needed; never capture money figures, dates of birth, names, emails; autocapture off for inputs; no network body capture.
- Identity: posthog.identify with the Better Auth user id only (no email or name); group by organization id so tenants are separate; reset on sign-out.
- Erasure and export: DELETE /api/me also deletes the PostHog person (PostHog API, server-side personal API key as an SST secret, EU host); export notes that analytics data is held by PostHog.
- Tenancy: a feature flag 'analytics' per tenant (default on) so a credit union can switch it off for its users.
- Docs: add PostHog as a sub-processor (EU region, DPA needed) to docs/gdpr-audit.md and the privacy notice list.

## Done when
- Without consent: no request to PostHog and no PostHog cookie or storage (checked in the browser).
- With consent: events and a recording arrive with inputs and text masked; withdrawing stops them and clears storage.
- DELETE /api/me calls PostHog person deletion (mocked in one API test).

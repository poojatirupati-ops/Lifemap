# Retirement and pension-access rules
status: done
deps: T2,T10
files: src/engine/retire.ts, src/engine/retire.test.ts

## Goal
Pure rules from sec 27.3 and 29: retirement age allowed from (age+1) to (planUntil-1) with calm notes below 50 and below 60 (never a block); pension access age 60 (50 if the customer says the scheme allows); State Pension at 66; income stops in the calendar year the retirement age is reached; bridge years = access age minus retirement age, paid from savings; partner's own retirement and State Pension. Returns data, no UI.

## Done when
Test at ages 40, 45, 50, 55, 60, 66, 75 with and without partner (bridge years, notes, bounds). npm run build and npm run lint pass.

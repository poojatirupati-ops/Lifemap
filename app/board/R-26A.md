## Goal
Port the rest of the original's "Your assumptions" (ASM, asmInput, asmScreen, p4Asm, calcAsmBlock) so step 7, Me > Your assumptions and the calculators' "Assumptions this tool uses" look and behave like the original. Remove every TODO(R-26).

## Built
- Step 7 "What we've set for you (change any)" now lists every Your assumptions field except plan-until age (shown above), in the original's order (`ASM_KEYS` minus planEnd). It reuses AssumptionField, so each field has its label, tag (Set by LifeMap / Assumed: add yours / Your choice), the suggested market-rate line, Back to LifeMap's figure or to the assumed rate, the unknown card/loan rate chips, units outside the box, and the original's min/max/step checks (ChoiceNumberBox, zod). Changing a field updates the plan, so results change. The open/closed state is remembered as 'p4', like `S.asmOpen`.
- PlanEndChoice: one component for the plan-until age. AgeChoices (step 7, the Plan length group) and the calculators both use it. The last-money tool now shows plan-until age with its other assumptions, as `calcAsmBlock` does. Before this it was filtered out.
- Me > Your assumptions Back: in the original, `S.asmBack` is only ever set to 'meback' (asmopen and gofix both set it). So Back to Me home already matches. The TODO is replaced by a comment that says so.
- assumptions.data.ts: the PLAN_END description stays because the calculators' kindOf and missing names use it. The TODO is gone.

## For other owners / questions
1. In step 7 and Me, "Investments grow" reads 2.6% with "less 38% exit tax" in the app. The original reads 2.7% with "less 35% exit tax" when the plan starts in 2027. The cause is in src/domain/planning/settings.ts: `standardOf` / `standardValue` default to rules2026 and do not use the plan's startYear rules (the original's invNet reads RI, which follows RULES_YEAR). The plan engine probably uses the same value, so Results/foundations are affected too. This was not fixed because the file is outside this card. Decision needed: who threads `rulesFor(startYear)` through standardValue('inv')?
2. tests/me/me.test.tsx fails 3 tests on `authClient.useListPasskeys` (MePrivacy Passkeys). Those failures come from the auth/passkeys work, not this card.
3. `npm run size` is 37508 lines; this card adds about 30 net lines (the new component, minus the copy removed from AgeChoices).

## Goal
GitHub Actions with official actions only: on PR run turbo lint, typecheck, test, build and the Playwright screen suite; on main deploy to a staging stage with SST using GitHub OIDC to an AWS role (aws-actions/configure-aws-credentials, no stored keys), run API and CMS migrations as a deploy step, then a smoke test; production deploy on a tagged release with manual approval (GitHub environments). Stage-specific config and secrets per SST stage; production stage has removal protection (removal: retain) and deletion protection on RDS.

## Done when
Workflows lint clean (actionlint); a dry run of sst diff documented; README has the release steps. Nothing deployed without the user's go-ahead.

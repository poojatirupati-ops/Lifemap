## Goal
Replace the stacked-screens App.tsx. Tiny hash router: screens in src/screens/*.tsx export default + `route = {path, tab?, public?}` (import.meta.glob). Routes are PROTECTED by default; only `public: true` routes (Welcome, WhyHere, Discover, Reveal, SignIn) render signed-out. The ONE guard redirects signed-out or expired users to /sign-in?returnTo=<path> and returns them after sign-in; shows a calm 'Your session ended' note on expiry. 5-tab bar Home/Explore/My Plan(centre)/Me/Experts, floating Ask button (AskSheet) shown only inside the tabs, hidden in onboarding (sec 17). shell/flow.data.ts holds the onboarding order: /welcome, /why, /discover, /reveal, /sign-in, then /home. Every authenticated screen card depends on this card.

## Goal
GET /me/consents and PUT /me/consents/:kind (withdraw as easy as give, timestamped, unticked by default), GET /me/export (one JSON file of everything held: account, plan, versions, consents, documents metadata, bookings), DELETE /me (removes account, plan, versions, documents, bookings, consents and the session; documents purged from storage). Session required.

## Done when
Tests: export contains only the caller's data; delete then every table has zero rows for that user and the session is dead; withdraw records a timestamp; 401 anonymous. npm run build and npm run lint pass.

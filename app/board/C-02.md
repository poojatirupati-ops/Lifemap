# Switch the app to CMS content
status: review
deps: C-01, T-MONO
files: app content loaders (videos, topics, explore categories, calculators intros, situations, live sessions, ask answers, personality types, legal pages)

## Goal
The app reads published content from the Payload REST API with TanStack Query (cached, with the seeded content as the offline fallback only if trivial), keyed by the existing app ids, and deletes the hard-coded *.data.ts copy it replaces. Videos play from Vimeo with @vimeo/player (dnt), loaded only on play. Legal page version feeds the consent version. Live preview via Payload preview package if cheap.

## Done when
Screens unchanged in the Playwright screen checks; editing a video title in the CMS and publishing shows in the app; `npm run size` lower.

## Goal
POST /documents (upload) allowed only for a verified account (403 otherwise: no uploads before verification, MASTER D8), stored in a private S3 bucket added to sst.config.ts (eu-west-1) through a small storage function (in-memory in tests). extract(file) is a pluggable function returning {docType, fields:[{key, value, confidence}]} per the workbook 'Document reader spec'; the default returns no fields (confidence 0) so nothing is invented and the customer falls to 'Type it'. GET /documents, DELETE /documents/:id. Per-user scoped.

## Done when
Tests: 403 unverified, 401 anonymous, upload plus list, fake extractor returns fields with confidence, cross-user fetch 404, delete removes the file. npm run build and npm run lint pass. sst.config.ts typechecks, nothing deployed.

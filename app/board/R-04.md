## Goal
For each fixture x screen id: :8080 gets S assigned + render() and its #screen DOM is read; the React app gets the same state via window.__lm; normalised DOM compared (post-effect DOM: hideEmoji, goalIcons, .pghead hoist applied; input .value normalised) plus a pixel diff. tests/scenarios/<card>.json replays click/type steps on both sides and compares S and DOM after every step (verifies handlers 1:1 without a dispatcher).

Rules (every card): read REACT-PLAN.md. DIRECT REWRITE, no bridge: the original ../LifeGoals-Customer-Journey-Prototype.html (served at :8080) is the reference for look, markup and logic; public/prototype.js is legacy and must not be read as a source of truth, copied from, or loaded. Same DOM, class names, ids, aria and data-* as the original; inline styles become style objects (unitless numbers, vendor prefixes, custom properties); no data-a dispatcher: components own handlers (React events) and effects (hooks); inputs uncontrolled (defaultValue + onInput); State is Zustand+immer (src/state/store.ts, R-02); domain logic is pure TS verified against the original script slice run in node:vm (tests/golden/origSlice.ts).

## Done when
- identical fakes pass, an altered fake exits 1 with a diff.
- cd app && npx tsc -b && npm test && npm run lint pass
- node tools/view-equal.mjs <the card's screen ids> reports 0 differences; node tools/visual-diff.mjs <the card's screens> is at or below 0.5% with no new tools/visual-allow.json entry (R-04 builds view-equal; until it exists use the pixel diff and scenarios)
- no file over about 150 lines; one component per file; touches only the files named above; public/prototype.js is never edited or loaded

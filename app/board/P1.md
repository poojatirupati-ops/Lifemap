# API production hardening
status: done
deps: S-01
files: ../api/src/app.ts, middleware, lambda.ts

## Goal
Hono built-in middleware only: secure-headers, cors (exact app, CMS and tenant origins), csrf for non-auth mutations, request-id, timeout, body limits on every route, one error handler that returns problem+json and never leaks stack traces or PII. AWS Lambda Powertools for TypeScript: Logger (JSON, request id, user and org ids only, PII redaction), Tracer (X-Ray), Metrics (sign-ins, plan saves, uploads, bookings, errors). Zod validation on every input (most already). npm audit clean or documented. Graceful DB errors (no 500s with SQL).

## Done when
Headers present on every response; no stack or SQL in any error body (one test); logs are JSON with request id and no email; tsc and tests pass.

## Notes (implementation)
- `api/src/app.ts`: request-id, secure-headers, cors (BETTER_AUTH_URL, CMS_URL, BETTER_AUTH_TRUSTED_ORIGINS, any tenant's https host), JSON access log + metrics, timeout 15 s, then the guard, then body-limit 1 MB (dev-files keeps its 10 MB) and csrf (not on /api/auth/*, Better Auth checks origins there). SES and S3 clients traced.
- `api/src/observe.ts`: Powertools Logger/Tracer/Metrics; `problem` = the one error handler (problem+json, no message/stack/SQL; Postgres class 22 -> 400). plan.ts uses it instead of its own.
- `api/src/lambda.ts`: Lambda context on logs, cold-start annotation/metric, metrics flushed per invocation (no middy).
- Metrics (namespace LifeMap): signIns (POST /api/auth/sign-in/* only; passkey/SSO callbacks not counted), planSaves, uploads (upload URL issued), bookings, errors.
- `sst.config.ts`: Api moved below the CMS (needs `cms.url` for CMS_URL), X-Ray active tracing + xray permissions.
- Route-level error responses still use `{ error }` JSON; only thrown errors are problem+json.
- npm audit: @hono/node-server bumped to 2.x (dev server only). Remaining api findings are dev-only (vitest 2 / esbuild / tinypool; fix = vitest major upgrade); next/sharp/happy-dom are cms/app workspace deps.

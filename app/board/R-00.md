## Goal
index.html loads only the prototype, so the earlier React app (src/App.tsx and friends) is dead code and its names (src/screens/Welcome.tsx, src/engine, src/state, src/components/*) collide with the layout PLAN.md wants. Move it unchanged into src/legacy/ with imports fixed so its tests keep running. It is kept only as a comparison target and is deleted in R-40. Nothing in it is reused unless a later card proves it equal by test.

Rules (all R cards): read REACT-PLAN.md first. Zero visual or behavioural change; converted screens emit the same DOM, class names, ids, aria and data-a/data-p attributes as the legacy view; inline styles become style objects (watch unitless numbers, vendor prefixes, custom properties); one component per PascalCase.tsx file, hooks in useX.ts, data in .data.ts, no speculative abstraction. Do not edit public/prototype.js unless Files says so. Estimate: about 150k tokens (writer plus reviewer).

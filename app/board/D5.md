## 1:1 match is measured, not judged (user requirement)
`node tools/visual-diff.mjs [screen]` screenshots the prototype (:8080) and the app (:5173) at 375x812 @2x after animations settle and fails a screen if more than 0.5% of pixels differ. Welcome currently fails at 93%. Add EVERY screen this card covers to `tools/visual-screens.json` (proto steps = visible button texts to click in the prototype to reach it; app = hash route and optional appSteps), and make them all pass. Method: do not re-design. Extract the prototype's exact markup structure, CSS rules, fonts, image files (copy from ../media into public/) and numbers for each screen and port them verbatim into components (still one component per file); then diff the output images in tools/out/*.diff.png and fix what lights up. The reviewer re-runs the tool and fails the card if any screen fails or any screen is missing from the JSON. Also add the same screens at 768x1024 only if the prototype itself has a distinct layout there.

status: done
deps: M-01

## Goal
Keep previous plan versions when the plan changes in a meaningful way (the app's version() points: goals changed, plan confirmed), list them and restore one; scoped to user and organization. Use the existing plan row with a small versions JSON array or a plan_version table only if needed (ponytail). App's Plan history screen reads and restores.

## Done when
API tests: list, restore, cross-user/tenant denial; app screen shows real versions.

## Backend (review)

In export and erasure. App: send `snapshot` where `addVersion` is called and read the history screen from the API.
